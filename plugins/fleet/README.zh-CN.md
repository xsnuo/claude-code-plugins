# fleet v0.2.1：会话总览

[English](README.md) | 简体中文 · [← 返回插件列表](../../README.zh-CN.md)

后台会话一多，想知道哪个在跑、哪个在等你、哪个做完了，就得回到 `claude agents` 去看。执行 `/fleet`，右侧弹出 `claude agents` 里全部会话的列表，不用离开当前会话就能一眼看清。列表下面是最新消息区：进入这个会话以后，别的会话一有新回复，就列在这里。

```
5 个会话 · 1 运行中 · 1 等你回复
✻ 产品需求文档整理                    2m
✻ 我的插件 当前                      30m
✻ 线上报错 帮我查一下                41m
✻ 🟢 发版                          3h 2m
✢ 老会话                          10h 2m
────────────────────────────────────────
最新消息
✻ 产品需求文档整理                    2m
```

## 安装

```
/plugin marketplace add xsnuo/claude-code-plugins
/plugin install fleet@xuesinuo
```

## 用法

- **打开、关闭**：执行 `/fleet`。也可以点面板右上角的 ✕ 关掉。
- **进入会话时自动打开**：执行 `/fleet auto on`，以后进入会话时自动打开，不用每次敲 `/fleet`；`/fleet auto off` 关掉（默认是关的）。设置会保存下来。
  - “进入会话”指：启动 Claude Code（包括 `claude --resume`、`claude --continue`）、后台会话（`claude attach` 连上时显示）、`/clear` 之后；
  - 不是你自己执行的打开，终端不够宽时 Claude Code 先不显示：不到 144 列（用 `/fleet` 打开过、没有手动关掉的，是 110 列）。拉宽终端，或者执行一次 `/fleet`，就显示出来。
- **看列表**：每个会话一行，从左到右是 Claude 的菊花标、会话名字、最近一次回复过了多久。
  - 菊花标的颜色就是状态：

    | 样子 | 状态 |
    |---|---|
    | 转动（橙色） | 运行中 |
    | 黄色 ✻ | 等你回复：一轮做完、最后问了你一句；正在问你问题；等你批准工具 |
    | 绿色 ✻ | 做完了 |
    | 红色 ✻ | 出错了 |
    | 灰色 ✻ | 被停掉了；或者开着但没在跑：新开还没提问的，定时醒来的会话在等下一次 |

  - 名字：会话的名字（`/rename`、`/tag` 改的就是它），没起名的用第一次提问；放不下的截掉，以 … 结尾。现在这个会话后面标着「当前」；
  - 时长：最近一次回复到现在过了多久。不到一分钟显示秒，比如 `3s`；满一分钟就不显示秒，比如 `2m`、`10h 2m`；满 24 小时显示 `24h+`；还没回复过的显示 `-`。正在跑的会话，显示的是上一次回复；
  - 最上面一行写着一共几个会话、几个运行中、几个等你回复；
  - 会话多、放不下时，用鼠标滚轮翻列表，上下各有一行写着还有几个。最新消息区不跟着翻，一直在列表下面。
- **排序**：最近回复过的排最上面。哪个会话一有新的回复（做完一轮、问你问题），就跳到第一行；在跑的会话留在它上一次回复的位置，做完了才跳上去。
- **最新消息区**：在列表下面，用一条线隔开；停靠在右侧时贴着面板底边，列表短时空着的地方留在列表下面。
  - 进入这个会话以后，别的会话有了新的回复（做完一轮、问你问题），它在列表里跳到第一行的同时，也列进最新消息区；只留最近 3 条，新的在上面，一个会话只占一行，再回复就更新；
  - 现在这个会话自己的回复不算；
  - 每次进入会话都清空，从这时候重新算。“进入会话”指：从 `claude agents` 打开、`claude attach`、启动 Claude Code（包括 `claude --resume`、`claude --continue`）、`/clear` 之后、手机或桌面端连上来；
  - 区域固定 3 行高，正好放下 3 条；不满 3 条时空着，来了新消息上面的列表也不会跳。
- **刷新**：面板开着时每 2 秒重读一次各会话的状态，时长每秒走一下，菊花标转动。面板关着、被别的面板挡住时什么都不读。
- **和目录（index 插件）一起用**：两个都停靠在右侧时是两个标签。
  - 会话的标签总在前面：目录先开着、再打开会话总览时，目录会先让开、等会话总览打开后再回来；
  - 进入会话时两个都自动打开的，显示会话总览；之后你点哪个标签就显示哪个；
  - 会话总览藏在目录后面时执行 `/fleet`，会把它显示到前面，不会关掉。
- **每段对话记住右侧栏**：会话总览开没开、显示的是会话总览还是目录，记在本机（目录开没开由 index 自己记）。
  - 重新打开这段对话（`claude --resume`、打开一个已经歇下来的后台会话）时照原样恢复，比 `/fleet auto on|off` 优先；
  - 没记过的对话照 `/fleet auto on|off` 来；
  - 只留最近 200 段对话的记录。
- **看现在的设置**：执行 `/fleet help`，列出所有用法和现在的设置。

### 列的是哪些会话

和 `claude agents` 一样：后台会话，包括已经做完、还留在列表里的。

- 后台会话是用 `claude --bg` 启动的、在 `claude agents` 里新建的那些；
- 在终端里直接 `claude` 启动、一直在前台的会话，`claude agents` 不列，这里也不列；
- 用 `claude rm` 删掉的，这里也就没有了。

## 运行要求

- **Claude Code 命令行（CLI）**，2.1.309 或更高版本（在这个版本上开发和测试）。不支持 VS Code 扩展、桌面 App 等其他形式。
- **最好开着 Claude Code 的全屏界面**，列表才会停靠在右侧。
  - 打开方式：执行 `/tui fullscreen`，或者在 `~/.claude/settings.json` 里写 `"tui": "fullscreen"`。
  - 这是 Claude Code 自己的界面模式，和终端窗口是否最大化无关。
  - 不在全屏界面、或者终端太窄（不到 110 列）时，列表显示在输入框上方。
  - 列表只用来看，不用点，所以不在全屏界面也能用。
- **macOS、Windows、Linux 都可以。** 插件只有 TypeScript 代码，不需要 Python，也不调用系统命令。目前只在 macOS 上实测过。

## 费用

不调用模型，不联网，不花钱。只读本机上 Claude Code 自己记的文件。

## 已知限制

- **读的是 Claude Code 未公开的内部文件**：`~/.claude/jobs/<id>/state.json`、`timeline.jsonl` 和 `~/.claude/sessions/*.json`（设了 `CLAUDE_CONFIG_DIR` 就在那个目录下）。Claude Code 升级后可能失效。
- **状态最多晚 2 秒显示。**
- **正在跑、在等你回复的会话，“最近一次回复”的时间要从 `timeline.jsonl` 里找。** 这个文件超过 4 MiB 时读不了：在等你回复的，改用状态文件最后更新的时间；正在跑的显示 `-`，除非面板开着时看到过它做完，那就用那一次的时间。
- **点一行不会切到那个会话。** Claude Code 2.1.309 不让后台会话里的插件切换会话：Claude Code 自己有“打开另一个后台会话”的功能，但在后台会话里是关着的，也没有给插件的接口。要进去还是在输入框为空时按 ←（或者执行 `/background`）回到 `claude agents` 里选，或者用 `claude attach <id>`。
- **看出“打开了会话”靠的也是 Claude Code 的内部文件。** 从 `claude agents` 打开会话不发任何事件，插件是看 `~/.claude/daemon/attach-journal/` 里有没有新的打开记录（每打开一次记一个文件）。这个记录不写打开的是哪个会话，所以不管打开哪个，所有会话的最新消息区都从那一刻重新算。只在一个终端里切换会话时这正好就是你要的；同时开着几个终端、各看一个会话时，在一个终端里打开会话，别的终端里的最新消息区也会清空。

## 开发

- **测试**：在本目录下运行 `claude plugin test .`。
- **文件**：

| 文件 | 作用 |
|---|---|
| `hooks/register.tsx` | 插件本体：`/fleet` 命令和设置、进入会话时自动打开、读各会话的文件、定时刷新、画列表和最新消息区 |
| `hooks/jobs.ts` | 纯逻辑：认状态（照着 `claude agents` 的规矩）、找最近一次回复的时间、排序、时长的写法、截断 |
| `hooks/layout.ts` | 面板排版：列表放不下时画哪一段、最新消息区画几条（最新消息区固定在列表下面，所以列表由插件自己翻） |
| `types/index.d.ts` | 插件状态的类型 |
| `tests/` | 插件测试，用模拟的文件、时钟和界面 |
