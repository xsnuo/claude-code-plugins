# index v0.4.1：对话目录

[English](README.md) | 简体中文 · [← 返回插件列表](../../README.zh-CN.md)

执行 `/index`，右侧弹出本次会话的目录：每一轮一项，上面是你那次提问的缩略，下面是 Claude 回答的一句话摘要。点一项，左边的对话就跳到那次提问的位置。重要的几轮可以收藏，收藏固定在目录顶上，点一下直接跳过去。

## 安装

```
/plugin marketplace add xsnuo/claude-code-plugins
/plugin install index@xuesinuo
```

## 用法

- **打开、关闭**：执行 `/index`。也可以点目录右上角的 ✕ 关掉。回答进行中也能随时打开。
- **进入会话时自动打开**：执行 `/index auto on`，以后进入会话时目录自动打开，不用每次敲 `/index`；`/index auto off` 关掉（默认是关的）。设置会保存下来。
  - “进入会话”指：启动 Claude Code（包括 `claude --resume`、`claude --continue`）、后台会话（`claude attach` 连上时显示）、`/clear` 之后；
  - 在会话里关掉目录，之后 `/reload-plugins` 不会再打开它，下次进入会话才会；
  - 不是你自己执行的打开，终端不够宽时 Claude Code 先不显示：不到 144 列（用 `/index` 打开过、没有手动关掉的，是 110 列）。拉宽终端，或者执行一次 `/index`，就显示出来。
- **每段对话记住目录开没开**：重新打开这段对话（`claude --resume`、打开一个已经歇下来的后台会话）时照原样恢复，比 `/index auto on|off` 优先；没记过的对话照 `/index auto on|off` 来。只留最近 200 段对话的记录。
- **和会话总览（fleet 插件）一起用**：进入会话时两个都自动打开的，目录等会话总览先打开（最多等 1.5 秒），显示的是会话总览；之后执行 `/index` 显示目录。见 [fleet 的说明](../fleet/README.zh-CN.md)。
- **看目录**：每一项两部分。
  - 上面是 ☆、序号和提问，默认最多折成两行，再放不下的截掉，以 … 结尾；`/index lines N` 改成最多 N 行（1 到 5），设置会保存下来；
  - 下面最多两行是回答的摘要；
  - 正在回答的那一轮显示「⋯ 回答中」，答完再写摘要；
  - 目录太长时用鼠标滚轮翻，最上面、最下面会写着还有几轮；打开时停在最后几轮，新的一轮会自动加在最后。
- **跳转**：点一项，左边的对话翻到那次提问，提问在屏幕最上面。
  - 太早的提问界面上还没画出来，插件会先往上一屏一屏地翻着找，会提示「正在往上翻找第 N 轮…」，一般一两秒；
  - 隔得特别远、一次没翻到时，会提示「再点一次，接着往上找」，再点一下就会接着找；
  - 正在看子代理的对话时，点一项会先回到主对话再跳。
- **收藏**：点一项前面的 ☆ 收藏这一轮，它变成 ★；再点 ★ 取消。
  - 收藏的几轮固定在目录最上面的「★ 收藏」栏里，列表怎么翻都不会被滚走；在下面的列表里也标着 ★；
  - 收藏时会记下那一轮在界面上的位置，点收藏栏里的一项直接跳过去，不用再往上翻找（收藏时还不知道位置的，第一次跳过去以后就记住了）；
  - 收藏时缓存那一轮的提问、回答原文和摘要。压缩对话以后，目录里没有这一轮了，收藏栏里还留着，标着「已压缩」；点它会把缓存的提问和回答复制到剪贴板；
  - 收藏属于当前这段对话：关掉目录、重新加载插件、重开或恢复会话都还在，`/clear` 之后清空；
  - 收藏栏最多占目录的四成高度，放不下的写着「还有 N 轮」，在下面的列表里按 ★ 找；每段对话最多收藏 30 轮。
- **摘要**：默认开着，在后台请 Claude（haiku）来写，一轮一次。
  - 只在目录打开时写，关着的时候不花钱；
  - 写过的会记在本机，下次打开、恢复会话都不再写；
  - 写摘要失败时显示回答的第一句，下次打开目录时再试；
  - `/index summary off`：不请 Claude 写，直接用回答的第一句；`/index summary on` 恢复。设置会保存下来。
- **看现在的设置**：执行 `/index help`，列出所有用法和现在的设置。

### 设置一览

| 命令 | 作用 | 默认 |
|---|---|---|
| `/index summary on\|off` | 摘要请 Claude 写，还是用回答的第一句 | on |
| `/index auto on\|off` | 进入会话时是否自动打开目录 | off |
| `/index lines N` | 提问最多折成几行（1 到 5） | 2 |

设置存在本机（Claude Code 给插件的存储里），所有会话通用。

### 什么算一轮

你发出一次提问，到下一次提问之前，算一轮；摘要按这一轮 Claude 的最后一段文字（最终回复）来写。

- 后台任务的通知、别的会话发来的消息不算一轮，也不会把它们引起的回复算进上一轮；
- 斜杠命令：触发了回答的（技能、提示词命令）算一轮，`/clear`、`/reload-plugins` 这类没有回答的本地命令不算；
- 被打断、没有文字回复的一轮，摘要显示「（没有文字回复）」；
- `/clear` 之后目录清空，从新的对话重新算。

## 运行要求

- **Claude Code 命令行（CLI）**，2.1.307 或更高版本（在这个版本上开发和测试）。不支持 VS Code 扩展、桌面 App 等其他形式。
- **开着 Claude Code 的全屏界面**，目录才会停靠在右侧，也才能点击跳转。
  - 打开方式：执行 `/tui fullscreen`，或者在 `~/.claude/settings.json` 里写 `"tui": "fullscreen"`。
  - 这是 Claude Code 自己的界面模式，和终端窗口是否最大化无关。
  - 不在全屏界面时，目录显示在输入框上方，只能看，点了不能跳。
  - 终端太窄（不到 110 列）时，目录也显示在输入框上方。
- **macOS、Windows、Linux 都可以。** 插件只有 TypeScript 代码，不需要 Python，也不调用系统命令。目前只在 macOS 上实测过。

## 费用

每一轮的摘要发一次请求，用 haiku、low 档位：
- **输入**：这一轮的提问（最多约 1500 字）和最终回复（最多约 8000 字，太长的取开头和结尾）；
- **输出**：一句话，几十个 token。

第一次在很长的会话里打开目录，会把还没写过摘要的每一轮都写一遍（新的先写，同时写两条）；之后只写新的一轮。开了自动打开（`/index auto on`）的话，恢复一个很长的老会话时也会这样。不想花这份钱就用 `/index summary off`。

## 已知限制

- **压缩对话（`/compact`）之前的轮次不在目录里。** 目录按现在的对话记录来列；压缩以后界面上也看不到之前的内容了。
- **只列最近 300 轮。**
- **在会话里用 `/resume` 换到别的会话，不会自动打开目录。** 目录开着的话照样开着。
- **跳转要知道那一行在界面上的位置。** 插件接口给的对话记录里没有每条消息的 id，插件是一边看界面画出来的行、一边按文字对上号的。收藏的几轮会记住位置。
  - 文字完全相同的几次提问（比如几次「继续」）靠先后顺序分辨，极少数情况下可能跳到相邻的那一次；
  - 被折叠、看不到的轮次跳不过去，会提示没找到。
- **摘要是 Claude 写的**，偶尔会不准，以原文为准。
- **收藏的内容缓存在本机**（Claude Code 给插件的存储里），提问最多存约 2000 字、回答最多约 3000 字；只留最近 10 段对话的收藏。

## 开发

- **测试**：在本目录下运行 `claude plugin test .`。
- **文件**：

| 文件 | 作用 |
|---|---|
| `hooks/register.tsx` | 插件本体：`/index` 命令和设置、进入会话时自动打开、目录面板、后台写摘要、点击跳转 |
| `hooks/turns.ts` | 纯逻辑：把对话记录切成一轮轮、显示用的截断和折行、写摘要的提示词、把目录项和界面上的行对上号 |
| `hooks/rows.ts` | 记下界面画过的行：提问行的 id 和先后，回复、工具调用行在对话记录里的位置 |
| `hooks/jump.ts` | 跳转：找到那一行（还没画出来就往上翻着找），再翻到屏幕顶上 |
| `hooks/favorites.ts` | 收藏：和目录里的轮次对上号、缓存哪些内容、存进本机的样子 |
| `hooks/layout.ts` | 目录列表自己翻动（收藏栏固定在顶上，所以目录不交给引擎翻） |
| `types/index.d.ts` | 插件状态的类型 |
| `tests/` | 插件测试，用模拟的引擎、模型和界面，不联网 |
